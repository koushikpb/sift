# Phase 3 — LoRA Clause Classifier: Eval Report

**Date:** 2026-06-30
**Gate:** before/after on the SAME test set, tuned component vs prompted baseline, metric-to-beat
declared in advance (LoRA macro-F1 ≥ baseline + 0.05). **Result: PASS — LoRA adopted.**

## Headline before/after (identical 371-item test subset, 37 CUAD clause types)

| Metric | Prompted baseline | LoRA (fine-tuned) | Δ | Bar |
|---|---|---|---|---|
| **macro-F1** | 0.6657 | **0.7177** | **+0.0520** | +0.05 → **PASS** (by +0.0020) |
| accuracy | 0.7439 | **0.8356** | **+0.0916** | decisive |

- **Baseline (before):** few-shot prompted `meta/llama-3.3-70b-instruct` (NIM), 2 in-context
  examples per class drawn from TRAIN only. `evals/reports/clf_baseline.json`.
- **LoRA (after):** Legal-BERT (`nlpaueb/legal-bert-base-uncased`) + LoRA (r=16, α=32,
  targets `query,value`), classifier + pooler trained via `modules_to_save`, best-of-10-epochs
  by val macro-F1 (best = epoch 9, val 0.6891). `evals/reports/clf_lora.json`.

## Decision
**Adopt the LoRA classifier.** It clears the pre-registered +0.05 macro-F1 rule and wins
accuracy decisively (+0.0916). The macro-F1 margin itself is thin (+0.0020 over the bar) and,
on a 371-item / 37-class subset with several rare classes, is within sampling noise; the robust
evidence for adoption is the accuracy gain plus the *breadth* of per-class improvement (most
classes improve, e.g. Document Name 0.667→0.960, Anti-Assignment 0.786→0.848, Change Of Control
0.727→0.800, Covenant Not To Sue 0.800→0.889; a few tie; one small class regresses to 0).

## Method (leak-free + fair)
- **Data:** CUAD extraction → 13,687 examples / 37 classes, **document-grouped** split
  (train 9379 / val 2111 / test 2197; 357/76/77 docs) so no contract spans train+test. Hard
  class-coverage anchoring guarantees all 37 classes appear in both train and test.
- **Same test set both sides:** `CLF_TEST_LIMIT=370` → a deterministic seeded stratified
  subsample (≥1/class, 371 items; seed 42). Baseline and LoRA are scored on the *identical*
  371 items, so the comparison is apples-to-apples. The subsample bounds NIM cost/quota
  (~10 min vs ~1 h) without biasing the comparison.
- **Fair baseline:** in-context examples come only from TRAIN; temperature 0; transport errors
  counted separately and aborted if >3% (actual: 3/371 = 0.8%, so the baseline is not deflated).

## Bugs / methodology issues caught and fixed during the gate run
1. **Frozen random pooler (gate-invalidating).** DeBERTa-v3 / Legal-BERT ship as MLM
   checkpoints with no SEQ_CLS `pooler.dense`; it was randomly initialized, frozen, and *not*
   saved with the adapter. Eval would have re-initialized a *different* random pooler →
   near-random LoRA score → a false "LoRA loses" result. Fixed by adding `pooler` (with
   `classifier`) to `modules_to_save` so it is trained *and* round-trips to eval
   (verified: trainable params 0.62M→1.21M; save/load round-trip exact in float32).
2. **MPS training ~21 h → ~50 min.** `DataCollatorWithPadding` pads each batch to its own max,
   so every new sequence length is a new tensor shape and MPS recompiles the graph almost
   every step (14–29 s/step). Fixed with fixed-length padding to `MAX_LEN=128` (one shape →
   compile once → ~0.5 s/step). Clauses are short (median 39 tok, 91.5% ≤ 128), so truncation
   loss is minimal. `MAX_LEN` is shared by train + eval for a fair score.

## Decisions recorded
- **Base model: Legal-BERT, not DeBERTa-v3.** DeBERTa-v3's disentangled attention falls back
  to CPU on Apple MPS (~21 h projected); Legal-BERT uses standard attention (native MPS,
  ~50 min) and is the planned legal-domain encoder. See `DECISIONS.md`.
- Prompt → RAG → Fine-tune decision for Layer 2 recorded in `DECISIONS.md` (2026-06-30).

```
make clf-extract                                  # data/processed/cuad_clf/{train,val,test}.jsonl
set -a; . ./.env; set +a                          # LLM_API_KEY, LLM_MODEL=llama-3.3-70b, LLM_RPM=36
CLF_TEST_LIMIT=370 make clf-baseline              # -> evals/reports/clf_baseline.json
CLF_BASE_MODEL=nlpaueb/legal-bert-base-uncased CLF_LORA_TARGETS=query,value CLF_MAX_LEN=128 make clf-train
CLF_BASE_MODEL=nlpaueb/legal-bert-base-uncased CLF_MAX_LEN=128 CLF_TEST_LIMIT=370 make clf-eval
```
